# Fees and accounting notes

## Average cost
We value positions with the average-cost method. Selling coins removes cost at the current average, so the average does not change when we sell.

## Fees paid in coins
When a fee is paid in the coin we bought, fewer coins arrive for the same money. When it is paid in the coin we sold, those fee coins also leave the position.

## Unsupported fee currencies
A fee in a third currency, such as an exchange token, is refused by the calculator. Convert it manually and record it as an adjustment after approval.

## Unrealized profit
Unrealized profit uses the latest recorded Binance price for each coin pair. If a price is missing, the value is unknown, not zero.
